# GATE XE 2027 Tracker

Live: https://shubhamkmaurya03.github.io/gatesyllabus/

A day-by-day study tracker for GATE XE 2027 (Engineering Mathematics XE0 + Materials Science XE2 + Thermodynamics XE4 + General Aptitude), 18 Nov 2026 → exam.

- **Today** – today's tasks, overdue tasks, what's coming up, deadlines and weak topics
- **Plan** – calendar heat-map, search, section filters, week-by-week day cards
- **Syllabus** – coverage of every official syllabus section + Weak / OK / Strong self-rating
- **Mocks** – log mock scores and see the trend
- **Fix my schedule** – spreads overdue tasks over the next 3–10 days (priority: applications → mocks → high-yield → practice), with undo

Progress is stored in the browser (localStorage). Use Export / Import under *Settings & guide* to move it between devices.

Single static `index.html`, no build step. GitHub Pages redeploys automatically on every push to `main`.
